# E-commerce funnel & drop-off analysis

## Problem statement

Where do users actually drop off between landing, product view, add-to-cart,
checkout, and purchase, and does that differ meaningfully by device, channel, or
geography? A secondary question: is there a segment where the funnel looks fine
in aggregate but is quietly broken underneath?

## Data source

bigquery-public-data.google_analytics_sample - real (anonymized) session-level
GA360 event data from the Google Merchandise Store.
